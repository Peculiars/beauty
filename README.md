# Beauty Admin App

## Overview
The Beauty Admin App is a web application designed for managing orders in a beauty product e-commerce platform. It provides an intuitive interface for administrators to view, edit, and manage customer orders efficiently.

## Features
- View detailed order information including items, customer details, and shipping address.
- Edit order status and revert changes.
- Access advanced editing features through Sanity Studio.
- Responsive design for optimal viewing on various devices.

## Setup Instructions
1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd beauty-admin-app
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up environment variables:**
   Copy the `.env.example` file to `.env` and fill in the necessary environment variables.

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. **Open your browser and navigate to:**
   ```
   http://localhost:3000
   ```

## Usage
- Navigate to the orders section to view and manage orders.
- Use the provided components to edit order details and shipping information.
- Utilize the API routes for any backend interactions.
